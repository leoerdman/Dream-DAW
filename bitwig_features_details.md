## Compressor+ and EQs (Focus, Sculpt, Tilt)\n\nCompressor+ (Bitwig Studio 5.2):\n- Character: Provides a range of compression styles (Smooth, Glue, Smash, etc.). Six total options.\n- Auto Timing: Tunes the chosen Character to best match the incoming signal.\n- Audio Analysis: Analyzes audio across four frequency bands with adjustable Intensity and Timing offsets per band.\n- Modes: Standard, Beyond (under/over-compression), and Dual (upwards compression).\n- VCA Colors: Analog (stable/moving) and Digital flavors.\n\nThree new EQs: Focus, Sculpt, Tilt\n- General: Inspired by classic hardware with modern controls and Stereo-ize feature.\n- Sculpt: Based on Pultec EQP-1; vintage broadband EQ for low-end sweetening. Saturation options: Tube, Transistor, Clean.\n- Focus: Based on MEQ-5 mid-range hardware EQ. Similar saturation options.\n- Tilt: Simple tone rebalancer for brightness/darkness with adjustable center frequency and slope.\n\n
## Micro-pitch Note FX\n\nThe Micro-pitch Note FX device in Bitwig Studio is designed for microtonal music production by enabling per-note microtuning beyond standard semitones. It offers categorized preset tunings—Historical, Theory, Cultural, Artistic—and integrates tightly with Bitwig’s instruments through programmable presets and Scala file import capability. This allows musicians to explore diverse tuning systems and expressive pitch modulation within their productions.\n\n- **Purpose:** Enables microtuning and microtonality (intervals smaller than a semitone).\n- **Pitch Handling:** Supports per-note pitch expressions and MPE for detailed customization.\n- **Preset Categories:**\n    - *Historical:* Scales like Werckmeister, Euler, Pythagoras.\n    - *Theory:* Just intonation, Otonal/Utonal series, A4=432Hz.\n    - *Cultural:* Arabic modes, Chinese instrument tunings, Javanese Chromatic 7.\n    - *Artistic:* Scales by musicians (Partch, Johnston) and performance layouts.\n- **Integration:** Part of the Essentials Collection; supports .SCL file import; works with note-specific modulators like Pitch-12.\n\n
\n## Convolution\n\n- Purpose: Imprints sound with an impulse response (IR) to create realistic or imagined spaces.\n- Included IRs: 270 impulses including cathedrals, train stations, studio gear (spring reverbs, pedals), and abstract environments.\n- True Stereo: Supports four-channel (true stereo) IR files.\n- Custom IRs: Any audio file can be dragged and dropped to be used as an impulse.\n- Features: Adjustable color and tone, and user-drawable envelopes to reshape the impulse response.\n
## The Grid\n\nThe Grid in Bitwig Studio is a modular sound-design environment powering three types of Grid devices: Poly Grid, FX Grid, and Note Grid.\n\n- **Modules**: Includes 231 modules across categories like I/O, Phase, Oscillator, Filter, Math, and Logic.\n- **Workflow**: Effortless patching where any signal is connectable to any other. All signals (audio and control) are stereo and 4x oversampled.\n- **Pre-cords**: Wireless connections for common signals via clickable icons.\n- **Interactive Help**: Each module has a help view describing parameters while allowing real-time tweaking.\n- **Integration**: Grid devices can be nested with other devices, controlled via Open Controller API, and integrated with hardware modular rigs via CV In/Out modules.\n\n
\n## Modulation System (Modulation Heaven)\n\nBitwig Studio's Modulation System Details:\n\n- **Number of Available Modulators:**\n  - Bitwig Studio offers 43 (and counting) different types of Modulators.\n  - The total number of Modulators per device is unlimited.\n\n- **How Modulators Work with Internal Devices and VST Plug-ins:**\n  - Every device in Bitwig Studio (Instruments, Audio Effects, Note Effects, and VST plug-ins) has Modulator slots.\n  - This allows inserting any modulators freely within every device.\n  - VST plug-ins also have Modulator slots, enabling expansion with modulation capabilities like LFOs, step sequencers, randomizers, and sidechaining.\n\n- **Concept of Modulator Slots:**\n  - Each device displays a Modulators icon in its bottom left corner to access the Modulators pane.\n  - One column of three slots is visible by default.\n  - Filling all three slots causes a new column with three more slots to appear.\n  - Users can add modulators by clicking \"+\" in the Modulators panel which opens a popup browser to select modulators.\n  - Modulators can be moved between slots by drag & drop.\n\n- **Process of Mapping a Modulator to a Parameter:**\n  - Each modulator has one or more modulation routing buttons (dot with arrow).\n  - Clicking the routing button activates Routing mode; parameters in the Device panel turn blue or green.\n  - In Routing mode, clicking and dragging parameters specifies the direction and depth at which the modulator output alters the parameter value.\n  - The Inspector panel allows viewing, editing, and removing modulation routings for better management.\n\n**Additional Features Related to Modulation:**\n- **Per-voice (polyphonic) modulation** is available for many modulators on internal Bitwig instruments. This toggles modulation from monophonic (blue) to polyphonic (green), modulating each note individually.\n- **Cross-modulation** is possible where one modulator can modulate parameters of another modulator.\n- **Nested devices** within main devices can also receive modulations.\n\nThis system provides flexible, limitless modulation possibilities integrated into every device and plug-in within Bitwig Studio.\n
## Modulation System\n\nBitwig Studio offers a state-of-the-art modulation system that is advanced, flexible, and intuitive.\n\n- **Number of Available Modulators**: 43 (and counting) different types of Modulators. The total number of Modulators per device is unlimited.\n- **Universal Compatibility**: Every device in Bitwig Studio (Instruments, Audio Effects, Note Effects, and VST plug-ins) has Modulator slots, allowing any modulator to be inserted into any device.\n- **Modulator Slots**: Each device features a Modulators icon in the bottom left. Clicking it opens a pane with slots. Filling three slots automatically opens a new column of three more.\n- **Mapping Process**: Each modulator has routing buttons (dot with arrow). Activating this mode allows you to click and drag parameters to set modulation depth. The Inspector panel provides a centralized view of all routings.\n- **Polyphonic Modulation**: Many modulators support per-voice (polyphonic) modulation for internal instruments, allowing each note to be modulated individually (indicated by green color vs. blue for monophonic).\n- **Cross-Modulation**: Modulators can modulate other modulators, and nested devices can also receive modulations.\n\n
\n## Hardware Integration\n\nBitwig Studio provides comprehensive hardware integration through dedicated devices (HW Instrument, MIDI CC, HW FX, HW CV Instrument/Out/In, HW Clock Out), supporting MIDI note/CC transmission, CV pitch/gate control for modular synths, built-in latency compensation on audio return paths, extensive modulation capabilities including Note FX applied to external gear, and synchronization options for drum machines and sequencers.\n\n- **Handling External MIDI Gear**: The HW Instrument device passes notes to gear via MIDI, supports MPE, and routes audio back with latency correction. The MIDI CC device sends CC messages for real-time parameter control.\n- **CV Integration**: HW CV Instrument sends Pitch and Gate signals to analog gear with tuning features. HW CV Out/In and HW Clock Out allow for precise software control and synchronization of modular rigs.\n- **Modulators & Note FX**: Over 30 modulators and various Note FX can be applied to external hardware, enabling unique custom device creation.\n
\n## Crash Protection and Plug-in Hosting\n\n- **Plug-in Support and Bit-Bridging:**\n  - Supports VST2.4, VST3, and CLAP plug-ins on all platforms.\n  - Native bit-bridging for 32-bit and 64-bit plug-ins on Windows and Linux; no third-party bridging necessary.\n  - Supports per-note expressions and sample-accurate automation (VST3 standard).\n\n- **Plug-in Sandboxing (Crash Protection):**\n  - Ensures a single plug-in crash does not take down the entire project.\n  - Isolates plug-ins to prevent interruptions during production or performance.\n\n- **Hosting Modes (Sandboxing Isolation Levels):**\n  - **Within Bitwig:** Plug-ins load with the audio engine (least memory, but least safe).\n  - **Together (Default):** Plug-ins are sandboxed together, separate from the audio engine.\n  - **By Manufacturer:** Individual sandboxes per manufacturer (useful for inter-plug-in communication).\n  - **By Plug-in:** Individual sandboxes per plug-in; instances of the same plug-in share a sandbox.\n  - **Individually:** Each plug-in instance is sandboxed individually (safest, most memory-intensive).\n\n- **Full Hosting Control:** Users can select hosting modes in the Bitwig Studio Dashboard to balance resource use and security.\n
\n## Touch Support\n\n- **Tablet Display Profile:** Includes a specialized keyboard layout designed for performing Bitwig Studio as an instrument. Supports pen technology for pressure-sensitive expressive performance.\n- **Radial Gesture Menu:** A multitouch feature for fast editing. Works with touch and pen for creating, copying, and deleting notes in the Note Editor.\n- **Touch Keyboard:** Supports expressive performance and MPE-like capabilities through pressure sensitivity.\n- **Hardware Integration:** Specifically optimized for devices like Microsoft Surface Pro, allowing intuitive gesture-based workflows for stretching, copying, and duplicating in the Arrangement view.\n- **Multi-touch Control:** Supports multi-touch for the Mixer, Drum Editor, and Note Editor, allowing simultaneous control of multiple parameters.
